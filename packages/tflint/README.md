# tflint

RPM packaging directory for `tflint`.

Template: `go`

This package is restricted to Fedora 44 and newer because upstream requires
Go 1.26.3 as of `tflint` 0.64.0. Fedora 43 still ships Go 1.25 and is
intentionally skipped.

Upstream:

- Git: https://github.com/terraform-linters/tflint.git
- Releases: https://github.com/terraform-linters/tflint/releases
